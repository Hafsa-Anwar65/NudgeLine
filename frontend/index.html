Features

Everything you need for a better first message

Less time staring at a blank box, more time on the replies that matter.

Comments that sound human

Short, specific replies that mention a detail from the post and match its language: English, Roman Urdu or a mix.

Personalized emails

A subject and body written from what you know about each lead, with your sign-off and an opt-out line added every time.

Website signals

Optionally reads a lead's homepage once, with plain HTTP and no browser, and uses real facts like their headline.

Skips what doesn't fit

Posts that are not a real need for your service are marked skipped, so you only review drafts worth sending.

Safe to stop and resume

Progress is saved as it goes. Run it again to continue, and failed rows are retried automatically.

Bring your own model

Works with Groq, Grok or Claude. Put one key in your .env file and you are ready.

How it works

From a list to ready-to-send drafts

Three steps, and one command each.

01

Add your posts or emails

Use a JSON or CSV file of fetched posts, or a CSV or plain text list of emails with any details you have.

02

Run Nudgeline

Pick comments or emails, and add --fetch-sites if you want it to read each lead's website too.

03

Review and send

Open the CSV, edit anything you like, then post or send each message yourself, in small batches.

$ python main.py comments --input posts.json
$ python main.py emails --input leads.csv --fetch-sites
Done. Review output/emails.csv, edit anything you like, then send yourself in small batches.
Principles

Built for outreach you can stand behind

Good outreach is honest, relevant and easy to say no to.

Drafts only

Nothing is posted or sent for you. You read, edit and send every message yourself.

Honest by design

Drafts use only the facts you provide. No invented results, prices or fake familiarity.

Easy to opt out

Every email ends with an opt-out line that you control in your profile file.
