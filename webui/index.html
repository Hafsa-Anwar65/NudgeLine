How the order and limits are set

Models are tried from top to bottom. When one runs out or fails, the next one takes over without stopping the run, and the first one is tried again once it recovers. Set the order in .env:

LLM_CHAIN=groq:llama-3.3-70b-versatile,groq:openai/gpt-oss-120b,xai:grok-4
# optional daily token budget after @ so the bar can show what is left:
# LLM_CHAIN=groq:llama-3.3-70b-versatile@500000,xai:grok-4@300000

Without LLM_CHAIN it is built from your keys in this order: Groq, Gemini, Cerebras, OpenRouter (free models), Grok, Claude (change with LLM_PROVIDER=groq,gemini,...). When a model's limit ends, its cooldown starts and the next model is used; afterwards the first available model in the list is used again. "Left" figures come from the provider's response headers when it sends them, otherwise from your budget. Restart python app.py after editing .env.
